⚡ How It Works

📢 SEV-1 alert fires in #incident-war-room
        │
        ▼ @triage-agent — 11 tool calls, 3m 16s
        🔍 Root cause: commit 8f2b31a "feat(payments): upgrade stripe sdk v3.4"
        │
        ▼ HANDOFF → @sre-agent
        🔧 npm pack stripe@3.4.0 → "Awaiting APPROVE"
        │
        ▼ Human: "APPROVE" (via Wispr Flow voice dictation)
        ✅ Rollback executed
        │
        ▼ @comms-agent → Post-mortem auto-generated 📄

🤖 The Three Agents

🔍

@triage-agent

Incident Detective. Ingests alerts & stack traces, correlates against git commits, isolates root cause commit with confidence metrics. Ran 11 tool calls in 3m 16s.

🔧

@sre-agent

Remediation Specialist. Prepares rollback plans, evaluates blast radius, executes bash/deployment commands — only after explicit human APPROVE.

📢

@comms-agent

Incident Commander & Scribe. Publishes stakeholder updates, tracks incident timeline, auto-generates structured post-mortems with MTTR and action items.
